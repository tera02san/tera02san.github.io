# インコカフェ AKI

奈良の小さなインコカフェ（架空）のサイトです。看板インコ3羽の魅力を伝え、InstagramのDMからの予約につなげることを目的にしています。

## ページ

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップ（看板インコ・インコ図鑑・メニュー＆料金・アルバム・お約束・店舗情報） |
| `plan-chokotto.html` / `plan-mattari.html` / `plan-oyatsu.html` | プランの詳細（ちょこっとプラン・まったりプラン・おやつあげ体験） |
| `inko-room.html` | インコ部屋のご紹介 |
| `photo.html` | インコちゃんと撮影会 |

## ファイル構成

CSSは役割ごとに分け、`base → layout → top / sub → motion → finish` の順に読み込みます。

| ファイル | 役割 |
| --- | --- |
| `css/base.css` | 色・フォントの変数、リセット、共通の文字設定 |
| `css/layout.css` | 見出し・ボタン・ヘッダー・フッターなどの共通パーツ |
| `css/top.css` | トップページ |
| `css/sub.css` | 下層ページ（プラン切り替え・各ブロック） |
| `css/motion.css` | アニメーションと、動きを減らす設定 |
| `css/finish.css` | 仕上げ（写真のかたち・文字組み・スマートフォンでの調整） |

- `script.js` … 全ページ共通。主な機能：
  - 動きのオン・オフ（前回の設定を覚えておく）
  - スマホ用メニュー
  - 看板インコのカード（スマホでは横スワイプ＋位置の目印）と「ごあいさつ」
  - インコ図鑑のタブ・写真の拡大表示
  - 今日の営業状況（日本時間で判定。祝日の一覧は毎年追加）
  - 日替わりランチの強調、DM文面のコピー
- `css/fonts.css` / `fonts/` … Fredoka（英字）、Zen Maru Gothic（日本語）。日本語はサイトで使う文字だけを入れたファイルです。

## 更新しやすさ

色はCSS変数にまとめ、営業時間・祝日は `script.js` の先頭近くの設定を直すだけで表示が切り替わるようにしています。
