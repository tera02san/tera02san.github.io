# 株式会社山口自動車. 店舗サイト（リデザイン）

奈良県御所市の自動車整備工場の既存サイトを、問い合わせにつながる店舗サイトとしてリデザインした作品です（お店の許可を得て掲載しています）。

## ページ

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップ（車検・新車販売・サービス・選ばれる理由・店舗案内・お問い合わせ） |
| `inspection.html` | 車検・整備（料金目安・流れ・予約フォーム） |
| `car-sales.html` | 新車販売（強み・オプション・スズキコネクト店・相談フォーム） |

## ファイル構成

- `style.css` … 全ページ共通。スマートフォンを基本に、600px / 900px / 1100px / 1280px で切り替え。色・角の丸み・余白は `:root` の変数にまとめています。
- `script.js` … 全ページ共通。機能ごとに `init○○()` に分けています。
  - スマホ用メニュー（Escキーで閉じる）
  - ヘッダーの影・トップへ戻るボタン
  - トップのスライドショー（一時停止ボタン付き）
  - よくあるご質問のアコーディオン
  - スクロールに合わせたフェードイン
  - お問い合わせフォーム（デモ：送信はしません）
  - 地図：ネットにつながっていないときは案内文を表示
- `fonts.css` / `fonts/` … Noto Sans JP（サイトで使う文字だけを入れた可変フォント1ファイル）
- `images/` … お店で撮影した写真と動画（`credits.txt` に一覧）

## 工夫したところ

- 社名の「.」は「円（縁）」を表すため、ロゴでは小さな正円として描いています（読み上げソフトには「.」として伝わります）。
- 動きを減らす設定（`prefers-reduced-motion`）の方には、スライドやフェードインを行いません。
