# 株式会社ソラミナ 採用サイト

クラウドソーシングに実際に出された過去の依頼案件をもとに、職業訓練校の授業で制作した採用サイトです。ポートフォリオ用に、社名・人物・数値・住所はすべて架空のものに置き換えています。

## ページ

| ファイル | 内容 |
| --- | --- |
| `index.html` | 採用トップ（事業の4本柱・数字・社員インタビュー・働き方・募集要項・エントリー） |
| `company.html` | 会社を知る（会社概要・ビジョン・アクセス） |

## ファイル構成

- `style.css` … 全ページ共通。スマートフォンを基本に、768px でPCのレイアウトに切り替え（メニューは1024px から横並び）。
- `script.js` … 全ページ共通。番号付きのコメントで機能ごとに区切っています。
  1. スクロールに合わせたフェードイン
  2. トップへ戻るボタン
  3. 社員インタビューのモーダル（フォーカスの閉じ込め・Escキー・背景クリックで閉じる）
  4. 数字のカウントアップ
  5. スマホ用メニュー
  6. 遷移先が未確定のリンクの処理
  7. スクロール誘導の矢印
  8. エントリーフォーム（デモ：送信はしません）
  9. 動きの一時停止ボタン
- `fonts.css` / `fonts/` … Noto Sans JP（本文・見出し・社名）、Zen Maru Gothic（キャッチコピーのみ）。どちらもサイトで使う文字だけを入れたファイルです。
- `images/` … 写真（JPEGとWebPの両方を用意し、`<picture>` で出し分け）、ロゴ（`logo-mark.svg`）

## 工夫したところ

- ロゴは事業の4本柱を4色の柱で表し、上端を右上がりにそろえて社名の「ソラ（空）」へ伸びる成長を表しています。
- 流れる写真と背景の動きは、一時停止ボタンでまとめて止められます。
