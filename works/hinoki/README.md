# Cafe HINOKI

吉野ひのきのカウンターがある、奈良の小さなカフェ（架空）のサイトです。

## ページ

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップ（時間帯で切り替わるスライド・コンセプト・空間・アクセス・お知らせ） |
| `menu.html` | メニュー（珈琲・お茶・モーニング・ランチ・甘いもの） |

## ファイル構成

- `css/style.css` … 全ページ共通。スマートフォンを基本に、600px / 900px で切り替え。
- `js/config.js` … お店の情報（曜日ごとの営業時間・定休日）。ここだけ直せば、営業状況の表示が切り替わります。
- `js/main.js` … 機能ごとに `init○○()` に分けています。
  - ナビゲーション（スマホ用メニュー）
  - トップのスライド：モーニング・ランチ・カフェタイムを、今の時間帯から表示（一時停止ボタン付き）
  - 今日の営業状況の表示
  - スクロールに合わせたフェードイン、ページ内リンク、トップへ戻るボタン
- `css/fonts.css` / `fonts/` … Allura・Cormorant Garamond（英字）、Shippori Mincho・Zen Kaku Gothic New（日本語）。日本語はサイトで使う文字だけを入れたファイルです。
- `img/` … 写真（出典は `img/credits.txt`）

## 工夫したところ

- 英字のフォントは先に読み込み（preload）、代わりの書体を一瞬表示しない設定（`font-display: block`）にして、ロゴや筆記体が読み込み中に動かないようにしています。
