# E.T. ポートフォリオ

Webデザイナーを目指して制作した作品をまとめたポートフォリオです。

## 見かた

`index.html` をブラウザで開いてください。
フォントやライブラリはすべてフォルダの中に入っているので、インターネットに接続していなくても表示できます（山口自動車.の地図だけは接続が必要です）。

## フォルダ構成

```
portfolio/
├── index.html            トップ（WORKS・SKILL）
├── works-*.html          各作品の説明ページ
├── css/                  ポートフォリオ本体のCSS（style.css / fonts.css / ress.css）
├── js/                   ポートフォリオ本体のJavaScript（jQuery 3.5.1 はローカルに保存）
├── img/                  サムネイル・作品画像・アイコン
├── fonts/                ポートフォリオ本体のフォント（Montserrat）
└── works/                Webサイト作品（それぞれ独立して動きます）
    ├── yamaguchi/        株式会社山口自動車. 店舗サイト（リデザイン）
    ├── solamina/         株式会社ソラミナ 採用サイト
    ├── aki/              インコカフェ AKI
    └── hinoki/           Cafe HINOKI
```

各作品のフォルダには、ファイル構成と実装した機能をまとめた `README.md` があります。

## 全作品で守っているルール

- PC・スマートフォンに対応したレスポンシブデザイン
- 文字の大きさはスマートフォンで14px以上、タブレット・PCで16px以上
- 文字と背景のコントラスト比は4.5:1以上。色だけに頼らず、形や文字でも情報を伝える
- 見出しは文節の切れ目（`<wbr>` ＋ `word-break: keep-all`）でだけ改行する
- 動きは一時停止ボタンと `prefers-reduced-motion` で止められる
- 画像は表示サイズに合わせて縮小・圧縮する
- Webフォントはサイトで使う文字だけを入れたファイル（サブセット）にして、1書体・1太さにつき1ファイルにまとめている
